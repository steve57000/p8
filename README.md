# Projet OpenClassrooms 1591 — Les Plus Beaux Logis de Paris

Le dossier regroupe les sources fournies, le notebook d’analyse exécuté, la prévision du portefeuille, les graphiques et la présentation de résultats.

- `livrables/Bell_Steve_1_Notebook_102026.ipynb` — étapes 1 à 3 avec calculs et graphiques.
- `livrables/predictions_valorisation_portefeuille_2022-12-31.csv` — estimation par actif.
- `livrables/Bell_Steve_2_presentation_102026.pptx` — support synthétique pour un interlocuteur non technique.
- `livrables/figures/` — graphiques exportés, dont la matrice de confusion K-means.
- `data/raw/` — copies inchangées des classeurs transmis.
- `PLAN_DE_TRAVAIL.md` — démarche, état et réserves.

L’estimation est un exercice pédagogique reposant sur les fichiers remis; elle ne remplace pas une expertise immobilière.
